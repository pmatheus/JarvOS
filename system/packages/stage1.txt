# JarvOS — stage 1: the packages the desktop needs to come up looking right.
#
# Installed with pacman only (official repos + the [jarvos] binary repo).
# Nothing here may compile on the user's machine: every AUR name below must be
# published as a prebuilt package in [jarvos].
#
# Everything else — browsers, editors, the security toolkit, the AI stack, CJK
# fonts, OCR, recording extras — lives in system/modules/*.module and is offered
# by the JarvOS Setup app at first login. Adding a package here costs install
# time for every user, so add only what a blank first boot would miss.
#
# One package per line, '#' comments and blank lines ignored.

efibootmgr
# The installer lays the target out as btrfs with @/@home/@log/@pkg subvolumes,
# so the installed system needs the userspace tools to manage what it boots from.
# Snapshot tooling (snapper, timeshift, grub-btrfs) is a first-run module: it
# changes nothing about how the desktop looks, and half-configured snapshots are
# worse than an explicit choice.
