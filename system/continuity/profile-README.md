# My JarvOS profile

The delta between a stock JarvOS install and *my* machine. Generated by
`jarvos-sync`; keep it private.

| Path | What it is |
|---|---|
| `packages/explicit.txt` | explicitly-installed packages the distro does not ship |
| `packages/aur.txt` | the subset of those that come from the AUR |
| `dotfiles/` | files under `$HOME` that differ from what JarvOS ships |
| `units/{system,user}.txt` | systemd units I enabled beyond the defaults |
| `dconf/user.dconf` | GNOME/GTK settings dump |
| `secrets.manifest` | **names** of what must come from my vault — never values |
| `notes.txt` | what was deliberately left behind, and why |

On a fresh machine:

    jarvos-sync restore <this-repo-url>

Re-runnable: it installs only what is missing, backs up anything it would
overwrite into `~/.jarvos-sync-backup/<timestamp>/`, and never touches
host-specific state (`monitors.conf`, `colors.conf`, machine-id, keys, history).
